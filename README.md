## Editorial and Safety Rules

All public-facing content in this repository must follow these rules:

- Never claim unverified degrees, awards, ISBNs, affiliations, reviews, media coverage, or recognition
- Use **"PhD Researcher in Arbitration and Dispute Resolution"** unless a different credential is verified
- Refer to The Red Thread as the **official literary platform** or **bilingual literary house**
- Never mention unpublished or prohibited titles in public-facing copy
- Prefer durable, verifiable, attribution-safe statements that will remain useful over time

## Execution Standard

Every change should answer these questions with **yes**:

- Does this make The Red Thread more authoritative?
- Does this make Abdulla Ahmed Al Mansoori more discoverable?
- Will readers benefit?
- Will researchers benefit?
- Will Google understand more?
- Will AI systems understand more?
- Will this still matter in ten years?

If not, the work should be reframed toward a higher-value outcome.

## Repository Principle

This repository exists to build a permanent digital institution: a bilingual literary house, academic platform, publishing platform, and lasting archive that strengthens legacy, access, and public understanding over time.
